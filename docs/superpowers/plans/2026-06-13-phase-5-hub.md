**Goal:** Turn the apex into a central hub with a public, opt-in **org directory**: an org's COMMAND can opt their org into a public listing (with a tagline); the apex `/orgs` page lists opted-in, LIVE orgs (name + tagline + link to their `<slug>.or9.space`). Default off — no org is listed without explicit COMMAND opt-in.

**Architecture:** Two new columns on the global `Tenant` table: `isListed Boolean @default(false)` + `tagline String?`. A COMMAND-gated action toggles them (the tenant row is global — written via `prismaGlobal`, guarded by `guardCommand` exactly like the config writers). A public query `listPublicOrgs()` reads `prismaGlobal.tenant` where `isListed=true AND status="LIVE"`, selecting ONLY public fields (slug, name, tagline) — this is an intentional cross-tenant read of opt-in public data (no RLS concern: `tenant` is a GLOBAL_TABLE). The apex `/orgs` page renders it with the marketing chrome.

export interface PublicOrg { slug: string; name: string; tagline: string | null; }
export async function listPublicOrgs(): Promise<PublicOrg[]> {
  return prismaGlobal.tenant.findMany({

`lib/actions/directory-core.ts` (reuse the guardCommand pattern — import it or replicate: it calls `requireTier(tenantId, accountId, "COMMAND")` and maps ForbiddenError → {ok:false}):
```ts
import { z } from "zod";
import { prismaGlobal } from "../db";
import { requireTier } from "../authz";
import { ForbiddenError } from "../permissions";

type Result = { ok: true } | { ok: false; error: string };

const Schema = z.object({ isListed: z.boolean(), tagline: z.string().trim().max(200).nullable().optional() }).strict();

export async function setDirectoryListingCore(tenantId: string, accountId: string, input: z.infer<typeof Schema>): Promise<Result> {
  try { await requireTier(tenantId, accountId, "COMMAND"); }
  catch (e) { if (e instanceof ForbiddenError) return { ok: false, error: e.message }; throw e; }
  const parsed = Schema.safeParse(input);
  if (!parsed.success) return { ok: false, error: parsed.error.issues[0]?.message ?? "Invalid" };
  const data: Record<string, unknown> = { isListed: parsed.data.isListed };
  if (parsed.data.tagline !== undefined) data.tagline = parsed.data.tagline;
  await prismaGlobal.tenant.update({ where: { id: tenantId }, data });
  return { ok: true };
}
```
NOTE: `requireTier` reads the membership via db(ctx) under the hood — confirm it works given just (tenantId, accountId) (it does, per Phase 2). The tenant UPDATE is on the global `tenant` table → `prismaGlobal` is correct (NOT db(ctx)).
